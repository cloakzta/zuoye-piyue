# 作业批阅助手 (Homework Marker)

> 轻量、高保真、开箱即用的在线作业批改与图片矢量批注工具。纯原生前端技术栈（HTML5 + Canvas + ES6），零后端、零依赖，开箱即用。

🌐 **在线体验 Demo**：[https://cloakzta.github.io/zuoye-piyue/](https://cloakzta.github.io/zuoye-piyue/)

---

## 🎯 核心解决的痛点

1. **拒绝繁琐教务系统**：
   - 无需注册登录、无建班和学生名单录入成本，打开网页即可立即批阅。
2. **多源极速导入**：
   - **剪贴板秒贴**：截图后直接在页面按 `Ctrl+V` / `Cmd+V` 即可导入作业；
   - **拖拽导入**：支持将单张或多张作业照片直接拖入浏览器窗口；
   - **多图连续批改**：底部缩略图栏自由切换，每份作业独立保存完整批改记录。
3. **专业教师批阅工具箱**：
   - **红笔 / 签字笔 (P)**：自由平滑手绘批改，手感丝滑；
   - **荧光笔 / 高亮 (H)**：半透明高亮画线，划重点不遮挡题干；采用**全局独立图层正片合成渲染**，彻底解决多次划线反复重叠变黑变脏的问题；
   - **智能几何橡皮擦 (E)**：
     - 采用**胶囊体（Capsule）连续几何裁剪**与**二分法亚像素求交截断**；
     - 擦除切口平整自然，告别锯齿与粗线条方块毛边；
     - 移动时连续插值追踪，快速划过不漏擦、不留残留断点；
   - **教师专属印章 (S)**：
     - 一键盖下 `✔ 正确`、`✘ 订正`、`💯 100分`、`👍 优秀`、`⭐ 阅`、`❓ 疑问` 印章；
     - **交互编辑**：点击任意印章可激活蓝色虚线高亮框与 4 个角缩放手柄；
     - **自由位移与缩放**：支持拖拽位移、手柄自由拖拉缩放，或通过悬浮栏精细步进缩放；
     - **快速清除**：支持点击印章右上角红叉 `(×)`、键盘 `Delete` / `Backspace` 键或悬浮按钮一键删除（支持无损撤销）；
   - **几何框选题 (R / C / A)**：矩形框、圆形/椭圆圈画、引导箭头；
   - **文本评语 (T)**：任意位置点击添加评语文字与扣分说明；
   - **完备撤销栈 (Ctrl+Z / Ctrl+Y)**：批阅过程每一步均可安全回退。
4. **高保真矢量渲染与离屏高清导出**：
   - **绝对物理坐标体系**：所有批注以原图物理像素为绝对基准，无论视口缩放到何种比例，批注位置均精准贴合原图；
   - **离屏无损导出**：以作业原图 100% 物理分辨率在后台渲染合并，导出的 PNG 清晰无损、不模糊、不压缩；
   - **一键复制到剪贴板**：批改完成一键写入系统剪贴板，可直接在微信/钉钉/QQ 聊天框粘贴发送给学生或家长。

## 🚀 快速启动与运行

### 方式 1：本地直接双击打开（最推荐）
无需配置任何服务器环境，直接双击项目中的 `homework_marker.html` 或 `index.html`，即可在任何现代浏览器（Chrome、Edge、Safari 等）中离线流畅运行。

### 方式 2：局域网 / Tailscale 跨端托管
教师在电脑（Mac / PC）上启动静态服务，可在手机、iPad 或触控平板上进行手写批改：

```bash
# Python 快速启动
cd homework-marker
python3 -m http.server 5173

# 或使用 npx serve
npx serve -l 5173
```

启动后：
- 本机访问：`http://localhost:5173`
- 手机 / iPad 访问：`http://[局域网IP或Tailscale_IP]:5173`

## 🛠️ 技术实现细节

- **纯原生前端**：不依赖 React/Vue 或 Fabric.js 等庞大第三方画布库，加载速度毫秒级，打包体积仅几十 KB；
- **自适应视口矩阵变换**：通过标准 2D 矩阵 `translate(panX, panY)` 与 `scale(s, s)` 映射屏幕像素与图片物理像素，实现平滑视口拖拽与缩放；
- **防叠加荧光笔**：采用分层离屏 Canvas（Offscreen Layer）统一绘制所有荧光笔路径，在整体合成时统一施加透明度渲染，避免同笔及交叉笔迹反复着色变黑；
- **几何级胶囊体擦除算法**：通过线段到胶囊体边界的二分查找算法实时截断路径，端点采用抗锯齿圆头融合，实现接近平板系统原生画板的清爽擦除质感。
